# ByaheGo – Frontend

React 19 + TypeScript + Vite + Tailwind CSS v4 + React Router.

```bash
npm install
cp .env.example .env      # set VITE_API_URL to your API (default http://localhost:8000)
npm run dev               # http://localhost:5173
npm run build             # production build in dist/
```

See the main [README](../README.md) for features, folder structure and deployment.
